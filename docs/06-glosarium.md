# Glosarium

## Baseline

Kondisi normal aplikasi sebelum pengujian dilakukan dan dipakai sebagai pembanding.

## Context

Lingkungan teknis tempat input diproses atau dirender, misalnya HTML body, attribute, JavaScript string, SQL clause, atau command argument.

## Sink

Titik tempat input akhirnya dipakai, dirender, dievaluasi, atau dieksekusi.

## Source

Titik asal data tidak tepercaya seperti form, query parameter, cookie, header, API client, atau data pihak ketiga.

## False Positive

Indikasi yang tampak seperti kerentanan, tetapi tidak bertahan setelah diverifikasi.

## Strong Signal

Perubahan respons yang konsisten dan cukup kuat untuk menjustifikasi verifikasi lanjutan.

## Reproducibility

Kemampuan menghasilkan hasil yang sama dengan langkah uji yang sama.

## Sanitization

Upaya membatasi, memodifikasi, atau membersihkan input sebelum diproses lebih lanjut.

## Output Encoding

Proses mengubah karakter khusus menjadi representasi aman sesuai konteks output.

## Parameterization

Pemisahan data dari instruksi query, umum dipakai untuk mencegah SQL injection.

## Allowlist

Pendekatan yang hanya mengizinkan nilai, pola, atau aksi yang sudah didefinisikan.

## Scope

Batas target, data, fitur, dan sistem yang diizinkan untuk diuji.
